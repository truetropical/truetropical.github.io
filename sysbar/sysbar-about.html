SysBar — About

Real-time hardware monitoring on your Windows taskbar. Free, ad-free, no telemetry.

Overview

SysBar is a lightweight, transparent taskbar widget that displays live CPU, GPU, RAM, Network and Disk stats directly alongside your system clock. No overlay windows. No floating panels. Just clean, always-visible stats that adapt natively to your Windows Light or Dark Mode theme.

No ads. No telemetry. No internet access. All sensor data comes from your local LibreHardwareMonitor instance running on your own machine.

Attribution

SysBar is built on the shoulders of the following open-source projects.

LibreHardwareMonitor

Provides all hardware sensor data via its Remote Web Server (localhost). SysBar queries LHM's JSON API to read CPU, GPU, RAM, disk and network metrics.

License: Mozilla Public License 2.0 (MPL-2.0)

nlohmann/json
