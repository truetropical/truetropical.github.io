SysBar — User Guide

Everything you need to get SysBar running and customised on your taskbar.

Requirements

  • LibreHardwareMonitor (LHM) must be running.
  • In LHM: Options → Remote Web Server → Enable
  • Default port is 8085. Change it in SysBar Settings if you use a different port.
  • Run LHM as Administrator for full sensor access (CPU power, some temps).

Getting Started

  1. Start LibreHardwareMonitor as Administrator.
  2. In LHM: Options → Remote Web Server → Enable.
  3. Launch SysBar — the widget appears left of your system clock.
  4. Left-click the widget at any time to instantly open Task Manager.
  5. Right-click the widget → Settings.
  6. Select which parameters to display (up to 6 columns).
  7. Select your GPU and Disk device if those parameters are enabled.
  8. Tick Run SysBar automatically on Windows startup if you want it to launch when you log in.
  9. Click Save.

Note: If SysBar starts automatically with Windows, it will remain invisible for the first 5 seconds to ensure your taskbar icons and LibreHardwareMonitor have finished loading.

Display Layout

  • Parameters pack 2 per column, related params placed adjacent where possible.
  • Network is always the rightmost column.
  • Disk is always second from right.
  • The widget grows leftward from the system clock as more params are enabled.
  • Maximum 6 columns. The Settings dialog will warn you if your selection exceeds this.
  • The widget and all dialogs will automatically adapt to your Windows Light or Dark Mode theme natively.

Network

  • All physical network adapters are aggregated into a single Up / Down reading.
  • Virtual, Bluetooth, Hyper-V, VMware, tunnel, Teredo and ISATAP adapters are automatically excluded.
  • You can manually select which adapters to include in Settings → Network Adapters.

Sensor Discovery

  • Sensors are discovered automatically from LHM on startup and refreshed every 60 seconds.
  • Works across LHM versions and hardware vendors (Intel, AMD, NVIDIA).
  • GPU and Disk selection in Settings lets you pin a specific device when multiple are present.

Status Indicators

N/A Sensor not present on this hardware (LHM is running, but this sensor doesn't exist for your CPU/GPU/etc.)
-- LHM is offline or not reachable. Start LHM and enable its Remote Web Server.
OFF No parameters selected in Settings.

Troubleshooting

  • Widget doesn't appear immediately on startup: This is intentional. SysBar waits 5 seconds on auto-start to allow LHM and taskbar icons to initialize without visual glitches.
  • Widget shows -- for everything: LHM is not running or its Remote Web Server is not enabled.
  • Some sensors show N/A: Normal — your hardware doesn't expose that sensor to LHM.
  • Wrong GPU selected: Open Settings and choose your GPU from the dropdown.
  • Network shows 0 or N/A: Check Settings → Network Adapters and ensure the correct adapter is selected.
  • Widget is on the far right instead of next to the clock: SysBar uses a safe fallback position if it cannot detect the standard Windows system tray (e.g., on secondary monitors or heavily modified shells).
  • CPU power / some temps always N/A: Run LHM as Administrator.
