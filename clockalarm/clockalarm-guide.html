ClockAlarm — User Guide

Everything you need to get ClockAlarm set up and running on your desktop.

Requirements

  • Windows 10 (1809+) or Windows 11, 64-bit.
  • .NET 8 Desktop Runtime — bundled in the MSIX installer, no separate download needed.
  • For Weather: a free API key from weatherapi.com (no credit card required).
  • No other dependencies, background services, or administrator rights required.

Getting Started

  1. Install ClockAlarm from GitHub MSIX package.
  2. Launch ClockAlarm — the widget appears on your desktop and can be placed anywhere.
  3. Drag the widget background to reposition it.
  4. Drag the bottom-right corner handle (◢) to resize. The layout scales automatically.
  5. Double-click the widget to cycle through display modes: Clock → Weather → World Clock → Countdown.
  6. Right-click the widget to open the main settings menu.
  7. To set your first alarm: right-click → Alarms → Add Alarm.
  8. To enable Weather: right-click → Weather Forecast and enter your WeatherAPI key and city.

Display Modes

  • Clock — Current time and date. The next upcoming alarm counts down prominently below the time.
  • Weather — Current conditions and forecast. Requires a WeatherAPI key configured in settings.
  • World Clock — Your home city alongside one alternative city (free), or an unlimited list of cities with a Timezone Conversion Calculator (Pro).
  • Countdown — Tracks days remaining to future events such as holidays or birthdays. Free tier supports 1 active event; Pro unlocks unlimited events.

Auto-Cycle

  • Enable Auto-Cycle in Settings to have the widget rotate through modes automatically.
  • Free: Rotates at fixed 5-minute intervals.
  • Pro: Set a precise custom interval of your choosing.

Alarms

  • Right-click the widget → Alarms to manage your alarm list.
  • The next upcoming alarm is displayed as a countdown on the main Clock screen.
  • Click All Alarms Holiday Off to silence all alarms temporarily without deleting them.

Appearance & Themes

  • Theme mode: Choose System (follows Windows), Dark, or Light.
  • Transparency: Adjust the widget background opacity via the transparency slider in Settings.
  • Clock format: Toggle 12/24-hour and choose from preset date formats.
  • Pro: Write your own custom date format strings (e.g. yyyy-MM-dd) and inject exact HEX colour values for full personalisation.

Weather Setup

  1. Register for a free API key at weatherapi.com — no credit card required.
  2. Right-click the widget → Weather Forecast.
  3. Enter your API key and your city name, then click Save.
  4. Weather will update silently in the background every 30 minutes.

Note: The free WeatherAPI tier supports up to 1 million calls per month — well above ClockAlarm's usage at 48 calls per day.

World Clock

  • Free: Displays your home city and one alternative city side-by-side. Daylight Saving Time is handled automatically.
  • Pro: Opens a dedicated floating World Clock window with an unlimited list of favourite cities and an interactive Timezone Conversion Calculator.
  • Configure your home city and additional cities via right-click → World Clock Settings.

Countdown Events

  • Track specific future dates — holidays, birthdays, deadlines — displayed on the Countdown widget mode.
  • Right-click → Countdown Events to add or manage events.
  • Free: 1 active event at a time.
  • Pro: Unlimited events and custom sounds per event.

Stopwatch & Timer (Pro only)

  • Dedicated resizable floating windows that operate entirely independently of the main widget.
  • Stopwatch: Includes lap time recording.
  • Timer: Custom durations, presets, background execution, and custom sounds.
  • Access via right-click → Stopwatch or Timer.

Troubleshooting

  • Weather shows an error: Check your API key is entered correctly and your city name is valid. Try the city name as it appears on weatherapi.com.
  • Weather stopped updating: Your free WeatherAPI key may have expired or been invalidated. Generate a new key at weatherapi.com.
  • Alarm didn't fire: Ensure the alarm is enabled (not in Holiday Mode) and the correct AM/PM is set for 12-hour format.
  • Widget appears behind other windows: Right-click → Always on Top to pin it above all other windows.
  • World Clock shows wrong time: Confirm your home city timezone is set correctly in World Clock Settings.
  • Widget lost its position after restart: Position is saved automatically on close. If it resets, check that ClockAlarm has write access to %LOCALAPPDATA%\ClockAlarm.
