ClockAlarm — User Guide

Everything you need to get ClockAlarm set up and running on your desktop.

Requirements

  • Windows 10 (1809+) or Windows 11, 64-bit.
  • .NET 8 Desktop Runtime — bundled in the MSIX installer, no separate download needed.
  • For Weather: a free API key from weatherapi.com (no credit card required).
  • No other dependencies, background services, or administrator rights required.

Getting Started

  1. Install ClockAlarm from GitHub MSIX package.
  2. Launch ClockAlarm — the widget appears on your desktop and can be placed anywhere.
  3. Drag the widget background to reposition it.
  4. Drag the bottom-right corner handle (◢) to resize. The layout scales automatically.
  5. Double-click the widget to cycle through display modes: Clock → Weather → World Clock → Countdown.
  6. Right-click the widget to open the main settings menu.
  7. To set your first alarm: right-click → Alarm Builder.
  8. To enable Weather: right-click → Settings > Weather Forecast and enter your WeatherAPI key and city.

Display Modes

  • Clock — Current time, date and next alarm.
  • Weather — Current conditions and forecast; configure a WeatherAPI key in settings.
  • World Clock — Shows home and alternative cities; the floating World Clock supports unlimited favourite cities and timezone conversion.
  • Countdown — Tracks unlimited future events.

Auto-Cycle

  • Use Settings > Widget Cycle Interval to select Off, 5 Minutes, or Custom Interval...

Managing Alarms

  • Use Alarm Builder to manage unlimited alarms.
  • Repeat by days of the week, date of month, every X days, or Nth weekday.
  • Choose standard Windows sounds or custom .wav files.
  • Use Settings > All Alarms Holiday Off to silence alarms temporarily.
  • The next alarm appears on the Clock display.

Appearance & Themes

  • Use Settings > Display Format to select System, Dark, Light or Custom.
  • Adjust Background Opacity and Text Opacity in Settings > Display Format.
  • Use Settings > Clock Format for 12/24-hour time and preset dates; use Settings > Clock Format > Custom Date Format… for custom date strings.
  • Use Settings > Display Format > Custom for custom HEX colours.

Weather Setup

  1. Register for a free API key at weatherapi.com — no credit card required.
  2. Right-click the widget → Settings > Weather Forecast.
  3. Enter your API key and your city name, then click Save.
  4. Weather will update silently in the background every 30 minutes.

Note: The free WeatherAPI tier supports up to 1 million calls per month — well above ClockAlarm's usage at 48 calls per day.

World Clock

  • The widget displays home and alternative cities.
  • Open World Clock for a floating window with unlimited favourite cities and timezone conversion.
  • Configure the home city and additional cities via Settings > World Clock.

Countdown Event Tracking

  • Use Countdown Event Builder to manage unlimited tracked events and custom sounds.

Stopwatch & Countdown Timer

  • Open Stopwatch or Countdown Timer for separate resizable windows.
  • Stopwatch records laps; Countdown Timer supports custom durations, presets, sounds and background execution.

Troubleshooting

  • Weather shows an error: Check your API key is entered correctly and your city name is valid. Try the city name as it appears on weatherapi.com.
  • Weather stopped updating: Your free WeatherAPI key may have expired or been invalidated. Generate a new key at weatherapi.com.
  • Alarm didn't fire: Ensure the alarm is enabled (not in Holiday Mode) and the correct AM/PM is set for 12-hour format.
  • Widget appears behind other windows: Right-click → Settings > Always on Top to pin it above all other windows.
  • World Clock shows wrong time: Confirm your home city timezone is set correctly via Settings > World Clock.
  • Widget lost its position after restart: Position is saved automatically on close. If it resets, check that ClockAlarm has write access to %AppData%\ClockAlarmWidget.
