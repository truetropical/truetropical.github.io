ClockAlarm — User Guide

Everything you need to get ClockAlarm set up and running on your desktop.

Requirements

  • Windows 10 (1809+) or Windows 11, 64-bit.
  • .NET 8 Desktop Runtime — install it from Microsoft if it is not already on your PC.
  • Weather (full version only): a free API key from visualcrossing.com (no credit card required).
  • No other dependencies, background services, or administrator rights required.

Getting Started

  1. Clicking the newsletter signup link at /contact/?subscribe=1 subscribes you to the TrueTropical newsletter: you receive a confirmation email, and the newsletter delivers the ClockAlarm-DotNet8.zip / ClockAlarm-Portable.zip download link. Download ClockAlarm-Portable.zip or ClockAlarm-DotNet8.zip using the TrueTropical newsletter; ClockAlarmFree on GitHub is the limited local-only version. Extract the zip and run ClockAlarm.exe.
  2. Launch ClockAlarm — the widget appears on your desktop and can be placed anywhere.
  3. Drag the widget background to reposition it.
  4. Drag the bottom-right corner handle (◢) to resize. The layout scales automatically.
  5. Double-click the widget to cycle through display modes: Clock → Weather (full version only) → World Clock → Countdown.
  6. Right-click the widget to open the main settings menu.
  7. To set your first alarm: right-click → Alarm Builder.
  8. To enable Weather: right-click → Settings > Weather Forecast and enter your Visual Crossing API key and city.

Display Modes

  • Clock — Current time, date and next alarm.
  • Weather (full version only) — Current conditions and forecast; configure a Visual Crossing API key in settings.
  • World Clock — Shows home and alternative cities; the floating World Clock, with unlimited favourites and timezone conversion, is full version only.
  • Countdown — Tracks events; unlimited events and custom sounds are full version only.

Auto-Cycle

  • Use Settings > Widget Cycle Interval to select Off, 5 Minutes, or Custom Interval (full version only).

Managing Alarms

  • Use Alarm Builder to manage unlimited alarms (full version only).
  • Repeat by days of the week, date of month, every X days, or Nth weekday (full version only).
  • Choose standard Windows sounds or custom .wav files (full version only).
  • Use Settings > All Alarms Holiday Off to silence alarms temporarily.
  • The next alarm appears on the Clock display.

Appearance & Themes

  • Use Settings > Display Format to select System, Dark, Light or Custom.
  • Adjust Background Opacity and Text Opacity in Settings > Display Format.
  • Use Settings > Clock Format for 12/24-hour time and preset dates; use Settings > Clock Format > Custom Date Format… for custom date strings (full version only).
  • Use Settings > Display Format > Custom for custom HEX colours (full version only).

Weather Setup (full version only)

  1. Register for a free API key at visualcrossing.com — no credit card required.
  2. Right-click the widget → Settings > Weather Forecast.
  3. Enter your API key and your city name, then click Save.
  4. Weather will update silently in the background every 30 minutes.

Note: A free Visual Crossing account is sufficient for typical personal use; see visualcrossing.com for current limits.

World Clock

  • The widget displays home and alternative cities.
  • Open World Clock for a floating window; unlimited favourites and timezone conversion are full version only.
  • Configure the home city and additional cities via Settings > World Clock.

Countdown Event Tracking

  • Use Countdown Event Builder to manage unlimited tracked events and custom sounds (full version only).

Stopwatch & Countdown Timer

  • Open Stopwatch (full version only) or Countdown Timer (full version only) for separate resizable windows.
  • Stopwatch records laps; Countdown Timer supports custom durations, presets, sounds and background execution.

Troubleshooting

  • Weather (full version only) shows an error: Check your API key is entered correctly and your city name is valid. Try the city name as it appears on visualcrossing.com.
  • Weather (full version only) stopped updating: Your Visual Crossing API key may have expired or been invalidated. Generate a new key at visualcrossing.com.
  • Alarm didn't fire: Ensure the alarm is enabled (not in Holiday Mode) and the correct AM/PM is set for 12-hour format.
  • Widget appears behind other windows: Right-click → Settings > Always on Top to pin it above all other windows.
  • World Clock shows wrong time: Confirm your home city timezone is set correctly via Settings > World Clock.
  • Widget lost its position after restart: Position is saved automatically on close. If it resets, check that ClockAlarm has write access to %AppData%\ClockAlarmWidget.
